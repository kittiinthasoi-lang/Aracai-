# ARACAI — คู่มือจัดการจักรวาลและสื่อ

## เป้าหมาย
ARACAI เป็นแอปศูนย์กลาง **มหากาพย์อารยาและอาราเซีย** ไม่ใช่เกมภารกิจ ไม่มีการสอบ ตอบคำถาม เก็บคะแนน หรือปลดล็อกบทเพื่ออ่านต่อ

## ส่วนที่มีในแอป
- **นิยาย** เล่ม 1 จำนวน 24 บท (ข้อมูลในโค้ดปัจจุบันเป็นฉบับเรียบเรียงย่อ ไม่ใช่ต้นฉบับ DOCX ครบทุกย่อหน้า)
- **ตัวละคร** ภาพ ข้อมูล พลัง และความสัมพันธ์จาก src/data/characters.ts
- **สารานุกรม** ข้อมูลโลกและตำนานจาก src/data/lore.ts
- **เส้นเวลา** จุดเปลี่ยนสำคัญของเรื่องในหน้าแอป
- **นิยายเสียง / อนิเมชั่น** แค็ตตาล็อกสำหรับเผยแพร่ไฟล์จริงที่มีสิทธิ์ใช้
- **การอ่านออกเสียงในเบราว์เซอร์** เป็นเสียงสังเคราะห์จากอุปกรณ์ ไม่ใช่เสียงพากย์ตอนที่ผลิตเสร็จ

## การเพิ่มสื่ออย่างถูกต้อง
1. ผลิตและตรวจสอบคุณภาพไฟล์เสียงหรือวิดีโอ พร้อมสิทธิ์การเผยแพร่
2. เก็บไฟล์เผยแพร่ไว้ใน `public/media/audio/` หรือ `public/media/video/` หรือโฮสติ้ง/CDN ที่มีสิทธิ์ใช้งาน
3. เพิ่ม `audioUrl` / `videoUrl` ใน `src/data/mediaCatalog.ts` โดยอ้างอิง URL ที่มีไฟล์จริงเท่านั้น
4. ทดสอบการเล่นบนมือถือและเดสก์ท็อปก่อนเผยแพร่

### ตอนนำร่องที่วางแผนไว้
**ตอนที่ 1 — สายใยแรกแห่งชะตา** ดัดแปลงจากเล่ม 1 บทที่ 1–3:
- การตั้งชื่อวาริน อาคิน และคีรัน
- ค่ำคืนแห่งการจู่โจมและการเสียสละ
- คำสัญญาของอารยาและการรับไครอสเป็นน้องเล็ก

สถานะ: **อยู่ในขั้นวางแผนการผลิต** ยังไม่มีไฟล์เสียงพากย์หรืออนิเมชั่นสำเร็จในแอป

## แนวทางเก็บต้นฉบับ
- ใช้เอกสารต้นฉบับเป็นแหล่งอ้างอิงหลัก ไม่สร้างคำพูดหรือเหตุการณ์ที่อ้างว่าเป็นต้นฉบับทั้งที่ดัดแปลง
- เล่ม 1 และเล่ม 2 แยกเป็นสองชุดข้อมูลพร้อมระบุสถานะชัดเจน
- **อย่านำต้นฉบับ DOCX ที่ยังไม่เผยแพร่ หรือไฟล์เสียง/ภาพต้นทางที่ยังไม่อนุญาต ลงในรีโพซิทอรี Public**
- หากต้องใส่ต้นฉบับฉบับเต็ม ให้ตรวจสิทธิ์และเปลี่ยนรีโพซิทอรีเป็น Private ก่อน แล้วสร้างกระบวนการนำเข้าที่รักษาข้อความทุกย่อหน้า

## การทดสอบ
```bash
npm install
npm run lint
npm run build
```
ตรวจเพิ่มเติมด้วยตนเองว่าเปิดอ่านได้ทุกบทโดยไม่มีภารกิจ การบันทึกหน้าทำงาน และแค็ตตาล็อกไม่แสดงสื่อที่ไม่มีไฟล์จริง
