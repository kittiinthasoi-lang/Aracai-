# ARACAI — The Story Universe

แอปศูนย์รวมมหากาพย์อารยาและอาราเซีย โดย กิตติอุซ KZ

## ฟีเจอร์
- หน้าแรกจักรวาลและทางลัดเข้าหมวดต่าง ๆ
- ห้องสมุดเล่ม 1 จำนวน 24 บทใน 6 ภาค เลือกอ่านได้ทั้งหมดโดยไม่ต้องปลดล็อก
- ค้นหาเนื้อหาบท บันทึกคั่นหน้า จำบทล่าสุด และปรับขนาดตัวอักษร
- อ่านออกเสียงภาษาไทยด้วย Web Speech ของอุปกรณ์ ไม่ใช่ไฟล์พากย์สตูดิโอ
- คลังตัวละครและภาพ สารานุกรมเผ่าพันธุ์/พลัง/สถานที่ และเส้นเวลา
- คลังนิยายเสียงและอนิเมชั่น พร้อมตัวเล่นเมื่อมีไฟล์จริง
- ธีมน้ำเงินเข้ม/น้ำเงินนีออน/ทอง รองรับมือถือ
- ไม่มีภารกิจ เกม คะแนน คำถามท้ายบท หรือการปลดล็อกบท

## ขอบเขตเนื้อหา
ข้อมูลใน src/data/bookData.ts ณ เวอร์ชันนี้เป็นฉบับเรียบเรียงย่อของเล่ม 1 จำนวน 24 บท ไม่ใช่ข้อความ DOCX ฉบับเต็มทุกย่อหน้า เล่ม 2 อยู่ระหว่างการเขียนและยังไม่ได้บรรจุลงรีโพซิทอรีนี้ จึงไม่อ้างว่ามีเล่ม 2 ครบ
ยังไม่มีไฟล์เสียงพากย์หรือวิดีโออนิเมชั่นที่สร้างเสร็จ เมื่อมีผลงานที่ได้รับสิทธิ์จึงเพิ่ม URL ใน src/data/mediaCatalog.ts เช่น /media/audio/ep01.mp3 หรือ /media/video/ep01.mp4 และวางไฟล์ใน public/media ที่ตรงกัน

## พัฒนา
ต้องติดตั้ง Node.js และ npm

    npm install
    npm run dev
    npm run lint
    npm run build

ค่าคั่นหน้า บทล่าสุด และขนาดตัวอักษรอยู่ใน localStorage ของอุปกรณ์ สามารถย้ายค่าบันทึกอ่านจากเวอร์ชันก่อนหน้าได้ โดยไม่ย้ายข้อมูลภารกิจ
