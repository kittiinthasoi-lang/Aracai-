# ARACIA • Story Quest
มหากาพย์อารยาและอาราเซีย โดย กิตติอุซ

เว็บแอปอ่านนิยายภาษาไทย ธีมน้ำเงินเข้ม น้ำเงินนีออน และทอง พร้อมต้นฉบับที่มีครบ 157 บท:
- เล่ม 1: 24 บท ฉบับสมบูรณ์
- เล่ม 2: บท 0–132 ยังอยู่ระหว่างการเขียน

## ใช้งาน
ติดตั้ง Python 3 และ Node.js จากนั้นใช้:

    npm start

เปิด http://localhost:8080

    npm test

ไม่มี npm dependency ใช้ browser ES modules และ DecompressionStream จึงต้องใช้เบราว์เซอร์รุ่นที่รองรับ API นี้

## ระบบ
- โหมดผจญภัย: ภารกิจเก็บเบาะแสท้ายทุกบท ตอบผิดแล้วลองใหม่ได้ ผ่านจึงปลดล็อกบทต่อไป
- ภารกิจปัจจุบันเป็นการเลือกข้อความเหตุการณ์ที่อยู่ในบท ไม่ใช่ระบบต่อสู้หรือทางเลือกแตกแขนงเต็มรูปแบบ
- โหมดอ่านอิสระ: เปิดได้ทุกบทโดยไม่ต้องผ่านภารกิจ
- ค้นหาเลข/ชื่อบท เลือกเล่ม ขยายตัวอักษร ย้อนหน้า บันทึกอัตโนมัติแยกเล่ม
- ส่งออก/นำเข้าบันทึกสำหรับย้ายอุปกรณ์ ไม่มี cloud account sync
- คำนำและส่วนต้นของต้นฉบับเก็บแยกไว้ มีทุกข้อความต้นฉบับรวม 953,650 ตัวอักษร ไม่รวมข้อความเกมที่เพิ่ม
- เล่ม 2 จบที่ต้นฉบับล่าสุด ไม่แสดงว่าจบเรื่องทั้งหมด

## เนื้อหาและการนำเข้า
ไฟล์ใน dist/books เป็น JSON บีบอัด gzip เพื่อลดขนาดโหลด ไม่ใช่การเข้ารหัส ข้อมูลบทมี heading, number, title, scenes; scenes.blocks เก็บย่อหน้าและ style ต้นฉบับ ภารกิจแยกด้วย kind: mission

สร้างไฟล์ข้อมูลใหม่จากชุดต้นฉบับด้วย python-docx:

    python3 scripts/import_novels.py /absolute/path/to/docx-folder

ใช้ต้นฉบับชุดละหนึ่งฉบับเท่านั้น เล่ม 1 ต้องมีบท 1–24 เล่ม 2 ต้องมีบท 0–132 สคริปต์ตรวจบทขาด/ซ้ำและตรวจจำนวนอักขระต้นฉบับกับข้อความส่งออก source-audit.json เก็บชื่อและ SHA-256 ของไฟล์ต้นทาง

## GitHub และโฮสติ้ง
Repository: https://github.com/kittiinthasoi-lang/Aracai-
Static hosting ใช้โฟลเดอร์ dist เป็น document root และต้องให้ไฟล์ .gz ดาวน์โหลดเป็น bytes (ไม่ใส่ Content-Encoding gzip เพราะแอปถอด gzip เอง)
GitHub เก็บ snapshot ของโค้ด/เนื้อหา การแก้บน GitHub ยังไม่ได้ตั้งให้ deploy ไป Sites อัตโนมัติ

## ขอบเขต
ยังไม่มีสมาชิก การซื้อบท คะแนนออนไลน์ หรือการตรวจป้องกันโกงบน server การเก็บ localStorage อาจหายเมื่อล้างข้อมูลเบราว์เซอร์ ผู้ใช้สำรองไฟล์บันทึกได้
ตรวจระบบด้วย Node tests; ยังไม่ได้ทำ browser visual QA ในสภาพแวดล้อมนี้

เนื้อเรื่องและภาพปกเป็นผลงานของผู้เขียน ไม่ให้สิทธิ์นำไปแจกจ่ายซ้ำเพียงเพราะเข้าถึง repository ได้
