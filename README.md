# ARACAI — The Story Universe

แอปศูนย์รวมมหากาพย์อารยาและอาราเซีย โดย กิตติอุซ KZ

## ฟีเจอร์
- เมื่อเปิดแอป **แสดงภาพปกหนังสือจริงขนาดใหญ่** ให้แตะภาพปกเพื่อเข้าสู่หน้าเลือกเพียง 2 ทาง: **จักรวาลอาราเซีย (อ่านนิยาย)** และ **สารานุกรมอาราเซีย**
- จักรวาลอาราเซียเปิดสารบัญที่สลับเล่ม 1/เล่ม 2 ได้ กดบทแล้วอ่านทันที
- สารานุกรมเปิดหน้าเลือก 8 หมวด ได้แก่ ตัวละคร เผ่าพันธุ์และสิ่งมีชีวิต พลังและความสามารถ สถานที่และอาณาจักร วิทยาการและสิ่งประดิษฐ์ องค์กรและสังคม ประวัติศาสตร์และเหตุการณ์ และนิยายเสียง/อนิเมชั่น โดยกดหัวข้อเพื่ออ่านรายละเอียดได้ พร้อมการค้นหา
- ห้องสมุดเล่ม 1 จำนวน 24 บทใน 6 ภาค และ **เล่ม 2 บทที่ 0–132 รวม 133 บท** เลือกอ่านได้ทั้งหมดโดยไม่ต้องปลดล็อก
- ค้นหาเนื้อหาบท บันทึกคั่นหน้า จำบทล่าสุด และปรับขนาดตัวอักษร
- อ่านออกเสียงภาษาไทยด้วย Web Speech ของอุปกรณ์ ไม่ใช่ไฟล์พากย์สตูดิโอ
- สารานุกรมเก็บข้อมูลตัวละคร/พลังจากข้อมูลเดิม รวมทั้งหมวดความรู้ที่ดึงจากเรื่องเล่า พร้อมระบุบทที่เกี่ยวข้องเพื่อกลับไปอ่านต้นฉบับ
- คลังนิยายเสียงและอนิเมชั่น พร้อมตัวเล่นเมื่อมีไฟล์จริง
- ธีมน้ำเงินเข้ม/น้ำเงินนีออน/ทอง รองรับมือถือ
- ไม่มีภารกิจ เกม คะแนน คำถามท้ายบท หรือการปลดล็อกบท

## ขอบเขตเนื้อหา
ข้อมูลใน src/data/bookData.ts เป็นฉบับเรียบเรียงย่อของเล่ม 1 จำนวน 24 บท ไม่ใช่ข้อความ DOCX ฉบับเต็มทุกย่อหน้า ส่วนเล่ม 2 นำเข้าเนื้อหา **133 บท (0–132)** จากเอกสาร DOCX ที่ผู้เขียนส่งมา 10 ชุด โดยแยกเป็น JSON รายช่วงบทใน public/books/volume2 ใช้ข้อความจากการสกัดเอกสารและจัดบรรทัดใหม่เพื่ออ่านบนเว็บ อาจมีความแตกต่างด้านช่องไฟจากต้นฉบับหน้าเอกสาร แต่ไม่มีภารกิจหรือข้อความเกมแทรก เล่ม 2 ยังอยู่ระหว่างการเขียน
ยังไม่มีไฟล์เสียงพากย์หรือวิดีโออนิเมชั่นที่สร้างเสร็จ เมื่อมีผลงานที่ได้รับสิทธิ์จึงเพิ่ม URL ใน src/data/mediaCatalog.ts เช่น /media/audio/ep01.mp3 หรือ /media/video/ep01.mp4 และวางไฟล์ใน public/media ที่ตรงกัน

## ข้อมูลเล่ม 2
- `src/data/volume2Catalog.ts` เก็บชื่อ 133 บทตามสารบัญเอกสาร และเส้นทางชุดข้อมูล 10 ไฟล์
- `src/components/VolumeTwoView.tsx` หน้าเล่ม 2 แยกจากเล่ม 1 พร้อมค้นหาชื่อบท อ่านต่อ คั่นหน้า ปรับตัวอักษร และอ่านออกเสียงด้วยระบบของอุปกรณ์
- `public/books/volume2/*.json` เป็นเนื้อหาจากชุด DOCX ที่แปลงเป็นข้อความและจัดย่อหน้าใหม่ โหลดทีละช่วงบทแบบ lazy load
- ตรวจสอบความครบของช่วงบท: 0–18, 19–41, 42–53, 54–60, 61–72, 73–87, 88–95, 96–114, 115–122, 123–132
- ข้อความจากการสกัดเอกสารควรตรวจทานการตัดบรรทัดและเว้นวรรคกับ DOCX ก่อนใช้เป็นต้นฉบับเผยแพร่มาตรฐานหรือผลิตสิ่งพิมพ์

## โครงสร้างการเปิดแอป (Navigation)

```text
เปิด ARACAI
└── ภาพปกหนังสือขนาดใหญ่ (แตะภาพปก)
    └── ประตูเข้าสู่จักรวาล (2 ตัวเลือก)
        ├── จักรวาลอาราเซีย
        │   └── สารบัญเล่ม 1 / เล่ม 2
        │       └── เลือกบท → อ่านนิยาย / คั่นหน้า / อ่านออกเสียงด้วยอุปกรณ์
        └── สารานุกรมอาราเซีย
            └── เลือกหมวด → เลือกหัวข้อ → อ่านข้อมูลและอ้างอิงบท
```

รายการสารานุกรมเป็นข้อมูลที่จัดหมวดแล้วในเวอร์ชันนี้ และออกแบบให้เติมหัวข้อจากเล่ม 2 ได้เพิ่มเติม ไม่ได้หมายถึงการทำดัชนีทุกชื่อเฉพาะจากต้นฉบับทั้ง 133 บทโดยอัตโนมัติ

ไฟล์หลักของโครงสร้างใหม่นี้: `src/App.tsx`, `src/components/EncyclopediaView.tsx`, `src/data/encyclopedia.ts`.
